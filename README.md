# ОРГАНИК — интерактивная 3D-модель

[Открыть модель](https://krasmur-rgb.github.io/ECO-System/)

Демонстрация внешнего корпуса и процессов очистки сточных вод на Three.js.

- Внешний корпус с фирменной окраской и логотипами.
- Последовательный обзор десяти узлов с переходом к совместной работе.
- Крупный план выбранного узла и управление камерой.

Можно скачать `index.html` и открыть его в современном браузере. Three.js, OrbitControls и логотипы встроены: внешние CDN не используются, сохранённый файл работает без интернета.

Модель демонстрационная: габариты, компоновка, длительности и часть технологических связей условны. Это не инженерная документация.

Three.js 0.180.0: MIT, см. THREE-LICENSE.txt. Фотографии и фирменная символика: [НПО Экосистема](https://eco-systema.com/).
